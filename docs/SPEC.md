# SPEC — 기능 명세

사용자(제작자 본인)가 서울대 로스쿨 면접을 기출 제시문으로 연습하는 정적 사이트. 아래가 전체 요구사항이며, "현재"는 샘플 코드가 이미 하는 것, "예정"은 `BUILD_PLAN.md`의 항목이다.

## 0. 공통

- 사이트 이름: **서울대학교 법학전문대학원 면접전형 대비** (앱바 브랜드, `<title>` 접미).
- 화면: 홈(`index.html`) · 모의면접(`practice.html`) · 기출DB(`db.html`) · 서가(`library.html`). 앱바 순서도 이와 같다.
- 반응형: PC(1280) · 태블릿(980 이하에서 1열) · 모바일(400). 가로 스크롤 금지.
- 글자 크기 4단계(14/16/18/20px, `html[data-font]`), 테마(시스템/밝게/어둡게, `html[data-theme]`), 블루라이트 차단(없음/하/중/상, 노란 오버레이 `mix-blend-mode: multiply`, 불투명도 .10/.20/.32). 기본값: 시스템 테마, 차단 없음, 보통 크기.
- 설정 서랍(톱니): 화면 / AI 면접관(제공사, API 키 저장·지우기, 기본 모델 select) / 모의면접 기본값(답변 방식, 흐름, 전사, TTS, 시간, 노크) / 초기화.
- 저장 위치(모두 브라우저):

| 항목 | 키 | 형식 |
|---|---|---|
| 설정 | `localStorage["snu-iv-settings-v1"]` | `app.js` DEFAULTS와 같은 키의 JSON |
| 녹음 | IndexedDB `snu-interview` / store `recordings` (keyPath `id`) | `{id, sessionId, setId, setLabel, modeLabel, question, createdAt, duration, mime, blob, filename}` |
| 기출DB 문답 | `localStorage["snu-db-threads-v1"]` | `{ [setId]: { [questionKey]: [{role:"user"|"ai", text, followup?, model?, at}] } }` |
| 서가 진도 | `localStorage["snu-library-progress-v1"]` | `{ [bookId]: 0..3 }` |

- API 키: `localStorage`에만. 저장소·코드·로그에 넣지 않는다. 설정 서랍에 [저장]/[지우기]와 "이 브라우저에 저장됨" 상태 표시.

## 1. 홈

- 히어로: 사이트 이름, 한 줄 요약, 세 화면 버튼, 시간표 띠(준비 20 → 대기 5 → 면접 15, 정적 `plan` 상태).
- 세 화면 소개(열 구분선), 수록 기출 세트 행(클릭 → `practice.html?set=<id>` → 모드 선택 단계), 다른 학교 칩("추가 예정"), 서울대 진행 방식(2025 복기 `format.basics`/`details`), 현재 설정 요약.

## 2. 모의면접

### 2.1 설정 3단계(한 화면, 번호 붙은 단계)

1. **세트**: 학교 토글(서울대 먼저, 세트 수 표시; 세트 없는 학교는 흐리게 + "복기 추가 예정") → 세트 행(연도·전형, 이름·세션, 주제, 제시문 수·복기 질문 수·트리 유무). 클릭하면 2단계로 내려가며 스크롤.
2. **모드**: `timed` 1-A 면접시간 AI 면접관 / `endless` 1-B 무한시간 AI 면접관 / `all` 2 무한시간 모든 질문 답변. 클릭하면 3단계.
3. **옵션과 시작**: 옵션 패널 + [시작] 버튼이 함께 나타난다.
   - 답변: 답변 방식(음성/텍스트), 전사(음성일 때: 브라우저 음성 인식/직접 입력), 질문 음성 읽기.
   - 시간표: 준비·대기·면접(분), 대기 여부, 노크(timed). 시간표 띠가 즉시 반영.
   - AI 면접관(AI 모드만): 난이도(하/중/상/최상), 변형도(하/중/상), 흐름(사전 결정 트리/실시간 생성).
   - AI 모델(AI 모드만): 제공사 seg + 모델 select(표시명; "직접 입력…" 옵션). **기본값은 설정 서랍의 값**이고 여기서 바꾼 값은 이 세션에만 쓴다. [기본값으로 저장]으로 설정에 반영. 키 상태 칩.
   - AI 입력 미리 보기(details): 첫 질문 생성 호출의 system/user 전문.
   - 답변 방식·전사·TTS·시간·난이도·변형도·흐름은 바꾸는 즉시 설정에 저장(= 다음 세션 기본값). 이전 단계 요약은 단계 머리에 표시되고 [바꾸기]로 되돌아간다.
   - `?set=<id>`로 들어오면 1단계를 건너뛰고 2단계부터.

### 2.2 세션

```
준비(prep) ──▶ 대기(wait, 옵션) ──▶ 면접(interview) ──▶ 종료(done)
```

- **진행 바**(sticky): 단계명 + 남은 시간(무제한이면 경과 시간) + 시간표 띠(지난 단계 채움, 현재 단계 진행 채움, 남은 1분은 붉은색) + 동작 버튼. 모바일에서는 띠가 둘째 줄.
- **준비**: 왼쪽 제시문(지시문 + 제시문 카드, 명조), 오른쪽 열(안내 카드 + 메모)은 **진행 바 아래에 sticky**(스크롤해도 따라온다, 열 안에서 스크롤). 메모 자동 저장(세션 상태). [준비 마침 → 대기/면접], [그만두기].
- **대기**: 제시문 숨김. 큰 시계 + "메모만 들고 들어간다" + 메모(편집 가능). [입실 → 면접].
- **면접**: 제시문 다시 표시(실제로 면접실에 비치됨). 오른쪽 sticky 열: 질문 카드 → 진행 목록 → 메모.
  - 질문 카드: 번호·출처(결정 트리/AI 면접관/학생 X Q n), 질문(명조), 답변 영역, 동작 버튼(같은 줄 같은 크기).
  - **음성**: [답변 시작] → 녹음(레벨 미터, 경과 시간) + 음성 인식 실시간 표시 → [답변 완료] → 녹음을 IndexedDB에 저장, 전사 수정 가능 → [다음 질문]. 전사 '직접 입력'이면 textarea에 요지를 적는다. [답변 없이 넘기기] 가능.
  - **텍스트**: textarea("답변을 작성하시오.") → [제출 → 다음 질문] / [넘기기] / [질문 듣기]. 녹음·마이크 없음.
  - 시간: `timed`는 면접 시간 종료 시 녹음 중이면 멈추고 자동 종료. 종료 1분 전 노크 소리 + 표시(옵션). 모든 단계 전환에 신호음.
  - 모바일: 제시문 / 면접 / 메모 탭.
- **종료**: 요약 칩, [같은 세트 다시] [다른 세트] [기출DB에서 보기], 이번 세션 녹음(재생·내려받기·삭제), 문답 기록(질문 + 전사/텍스트), 메모, 이 세트의 복기 질문 전체.
- 세션 중 페이지 이탈 경고(`beforeunload`), 화면 꺼짐 방지(`wakeLock`).

### 2.3 다음 질문 결정 (AI 모드)

1. `all` 모드: 복기 질문 은행을 학생 A → B → … 공통 순으로 전부.
2. 흐름 `tree`이고 세트에 `tree`가 있으면 트리를 걷는다. 분기 노드에서는 `classify`(경량: 답변 전사 + 분기 조건만)로 가지 선택; 키 없으면 사용자가 가지를 고른다. 트리 끝 → 키 있으면 실시간 생성, 없으면 질문 은행.
3. 흐름 `live` 또는 트리 없음: `nextQuestion`(제시문 전문 + 복기 질문 전체 + 지금까지의 문답 + 난이도·변형도 지침) → `{question, focus, why}`.
4. 키 없음·호출 실패: 질문 은행(중복 제거)으로 대체하고 오류를 카드에 표시.

### 2.4 녹음 보관함

설정 화면 하단. 모든 세션의 녹음을 최신순으로 재생·내려받기·삭제. (예정) 세션별 묶음, zip 일괄 내려받기, 전사 붙이기.

## 3. 기출DB

- 학교 토글 → 왼쪽(sticky) 세트 목록(+ 문답 수) + 학교 진행 방식(fold) / 오른쪽 세트 상세.
- 세트 상세: 머리(학교·연도·세션·전형, 이름, 주제 칩, [이 세트로 모의면접]), AI 바(제공사 seg, 모델 select, 키 칩 — 기본값은 설정, 이 화면에서만 바뀜), 제시문 fold(기본 펼침), 복기 추가질문(학생별·공통 그룹).
- 질문 행 클릭 → 스레드: 기존 문답(나/면접관 + 꼬리질문), textarea, [AI 면접관에게 보내기](키 없으면 비활성) / [기록만 남기기] / [기록 지우기], "AI 입력 보기"(system/user 전문).
- `respond` → `{feedback, followup}`; 꼬리질문에 이어서 답할 수 있다. 문답은 localStorage에 즉시 저장.
- 해시 `#<setId>`로 세트를 연다. (예정) 스레드 내보내기, 검색·필터, 모의면접 문답 기록과 연결.

## 4. 면접대비 서가

도서 100선 뷰어(원본 HTML에서 이식). 개요(등급 분포, 진도, 먼저 읽을 7권, 아홉 분야, 선정 기준) / 도서(검색·등급·분야·판본·정렬·진도 필터) / 쟁점(18개, 사실·축·활용·질문·90초 구술 틀) / 읽는 순서(독서 시간 계산기, 단계, 짝지어 읽기, 전체 순위). 책 상세 서랍(해시 `#b<id>`), 진도 0~3 기록. (예정) 연결 지도 SVG, 효용–비용 산점도, 읽는 범위–쟁점 그래프, 쟁점×분야 매트릭스, 진도 내보내기/가져오기.

## 5. AI 연동 요약

`docs/AI.md` 참조. 제공사 Anthropic/OpenAI, 브라우저 직접 호출, 모델은 `data/models.js` 목록에서 선택(직접 입력 가능). 모든 질문 생성·검토 호출에 제시문 전문과 복기 질문 전체가 들어간다. Claude API는 오디오 입력이 없으므로 전사는 OpenAI 전사 API 또는 로컬 스크립트(`docs/TRANSCRIPTION.md`).

## 6. 브라우저 지원

Chrome(데스크톱·안드로이드) 기준. Safari: 녹음 mp4, 음성 인식 가능. Firefox: 음성 인식 없음(직접 입력/텍스트 모드). `file://`에서도 동작.
